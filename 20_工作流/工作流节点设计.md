## 逐节点规格

### ① 接收写作任务
- **输入**：用户一句诉求（可能很随意："写一篇关于××的推文"）
- **动作**：只提取 4 项——主题、文体线索、目标读者、字数要求
- **输出**：任务卡（内部）
- **失败处理**：主题包含多个独立选题 → 先问用户"先写哪一个"

### ② 文体与读者判定
- **输入**：任务卡
- **动作**：匹配 KB2 文体变体规则 → 输出 `STD / AVOID / HEALTH / SAFETY / MISC`
- **输出**：文体标签 + 该文体的标题/结构/语气/资料/结尾差异清单
- **失败处理**：无法唯一判定 → 问用户"更接近哪一种"（一次只问一个问题）

### ③ 风格检索（**与步骤 ④ 物理隔离**）
- **数据来源**：KB2 规则卡（首选）+ KB1 结构骨架
- **动作**：
  1. 按文体取回 **5–10 篇**相近语料，**只提取结构骨架**（段落功能序列、句长分布、开头/结尾模式）；
  2. 从 KB2 取回该文体全部 C/R/T 级规则卡；
  3. 标注每条规则的等级与例外。
- **产出**：`风格执行单.md`（内部）
- **禁止**：把 KB1 原文段落写入产出；把 KB1 内容标为事实
- **失败处理**：同文体语料 <3 篇 → **挂起**，提示"该文体样本不足，无法保证'像我'"

### ④ 事实检索（**与步骤 ③ 物理隔离**）
- **数据来源**：**仅 KB3**（历史语料库严禁进入）
- **动作**：按主题关键词收集本次资料；每条事实标来源与 🟩/🟨
- **产出**：`资料池.md`（内部）
- **失败处理**：**无本次资料 → 立即暂停**，输出补料清单

### ⑤ 建立事实底稿
- **动作**：逐条列 事实点 / 数值原表述 / 来源 / 状态 / 核验日期 / 拟用段落
- **产出**：`KB3-<run>/事实底稿.md`
- **G2 事实完备闸**：若 `[待核验]` 项属于文章支点（标准号、限值、核心结论）→ **暂停**，固定话术：
  > ⏸ 已暂停：事实底稿中 F__、F__ 缺来源。请补充【具体文件/官方链接】。
  > 我不在资料不足时先写占位稿。

### ⑥ 标题与结构（内部产物）
- **输入**：文体标签 + 风格执行单 + 事实底稿
- **动作**：3 个标题候选 + 结构骨架（每节功能 + 拟用事实编号）
- **输出**：`结构骨架.md`（内部）
- **⚠️ 硬约束**：**不向用户展示**。只有通过节点 9 后才可能出现在最终交付里（作为标题备选）

### ⑦ 生成正文
- **输入**：结构骨架 + 事实底稿 + KB2 规则卡
- **硬约束**：
  - 事实只引用底稿中 🟩 项；
  - 风格只依据规则卡，**不得调取 KB1 原文**；
  - 字数按用户设定区间；
  - 内部先跑一遍"重复自检"（对 KB1 做 n-gram 指纹比对，连续 ≥12 字命中 → 自动改写）
- **产出**：草稿 v1

### ⑧ 事实审校（独立）
- **执行方**：独立子代理，**看不到**节点 ⑦ 的写作过程与自辩
- **动作**：逐句切分 → 每个数字/标准号/日期/结论回到 KB3 核对 → 输出问题清单
- **通过标准**：零"无来源事实"、零 🟨 入稿
- **失败处理**：有问题 → 打回节点 ⑦（**本节点无放行权**）

### ⑨ 风格审校（独立）
- **动作**：
  1. 对照 KB2 规则卡逐条打分（含开头/节奏/结尾专项）；
  2. 与 KB1 做片段指纹比对，检测洗稿；
  3. 检测"AI 味黑名单"命中。
- **通过标准**：规则符合率达标 **且** 零重复命中
- **失败处理**：打回节点 ⑦；**不得**与节点 ⑧ 互相看到结论

### ⑩ 发布合规自查
- **动作**：禁用词 / 绝对化用语 / 恐慌式表达 / 标题党 / 医疗断言 / 来源标注完整性 / 免责与适用边界是否写明
- **通过标准**：零命中
- **失败处理**：打回节点 ⑦

### ⑪ 输出最终成稿
- **动作**：只输出成稿正文（+ 通过后的标题备选，若用户曾要求）
- **硬约束**：**不输出**分析过程、结构骨架、修改说明、评分明细（除非用户明确要求）

## 三条 Gate 汇总

| 闸 | 位置 | 判定 | 动作 |
|---|---|---|---|
| **G1 检索隔离** | ③④ 之间 | 风格检索与事实检索是否分开执行、分别产出 | 未分开 → 重做 |
| **G2 事实完备** | ⑤ 之后 | 支点事实是否全部 🟩 | 有 🟨 → 暂停补料 |
| **G3 重复** | ⑨ 内 | 与 KB1 连续 ≥12 字 / 独特比喻命中 | 命中 → 打回重写 |

## 独立性保障（防止"自己查自己"）
1. ⑧⑨⑩ 由**独立上下文**执行，输入只有成稿 + 各自的知识库，**不含写作对话**；
2. ⑧、⑨ **互相不可见**对方结论；
3. 审校节点**只有否决权，无放行权**，改写统一回到 ⑦；
4. 三个节点全部通过才进入 ⑪。

## 暂停条件清单（触发即停，不硬写）
- 同文体语料 <3 篇（③）
- 本次无事实资料（④）
- 支点事实存在 🟨（⑤）
- 用户指定的必须保留习惯与本次事实冲突（⑦ 前）
- 标准号/条款无法溯源（⑧）
- 用户要求的表述与合规禁忌冲突（⑩）
