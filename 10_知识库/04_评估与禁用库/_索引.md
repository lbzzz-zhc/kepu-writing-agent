# KB4 · 评估与禁用库

## 存放四类内容

**① 禁用清单**（`禁用清单_v0.1.md`）
- 禁用词、禁用句式、禁用腔调（学术腔 / 营销腔 / 恐慌式表达 / 绝对化用语 / 标题党）
- 每条标注：禁用理由 + 替代写法

**② 测试集**（见 `30_测试集/`）
- 10+ 个测试任务，覆盖不同主题与文体
- 每任务含：请求原文、正确文体判断、必守风格、易错点、评分标准

**③ 评分卡**
- 事实维度：无来源事实数、🟨 入稿数、编号/限值错漏
- 风格维度：规则符合率、段落节奏、开头/结尾达标
- 合规维度：禁用词命中、绝对化用语、恐慌式表达

**④ 误用记录（实战台账）**
| 日期 | 文章/run | 问题类型 | 具体表现 | 处置 | 是否已回写规则 |
|---|---|---|---|---|---|
|  |  | 旧数据继承 / 洗稿 / 腔调跑偏 |  |  |  |

> 这一栏是"越用越准"的关键：每一次翻车都要回写成一条硬规则，否则同一个坑会再踩。
