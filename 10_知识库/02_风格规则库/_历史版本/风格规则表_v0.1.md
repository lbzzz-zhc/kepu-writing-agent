# 风格证据表 v0.1（13 篇基准）

> 生成日期：2026-09-12　语料基准：**13 篇**（KB1 共 14 个文件，其中 1 篇为同题异版本，已排除计数）
> 统计口径：正文净字数（不含标题、图片位、来源清单）
> 等级定义：**R** 同文体 ≥5 篇且无明显例外｜**T** 3–4 篇或存在例外｜**O** 1–2 篇（不入库）

## 一、R 级规则（可直接注入 KB2，写作时默认执行）

### R-01 开篇必须是场景锚点，首段不出现标准号
| 项 | 内容 |
|---|---|
| 维度 | 开篇方式 |
| 可执行 | 第 1 段 30–110 字（实测均值 82），只写**时令、生活动作或人群情境**；主题在第 2–3 句出现；**首段不出现任何标准号，不出现"标准""规定"字样** |
| 证据 | **13/13（100%）**，代表：全部 |
| 频率 | 100%，无例外 |
| 锚点三型 | 时令型 10/13（炎炎夏日／秋意渐浓／初春时节乍暖还寒／二月春风似剪刀）；生活动作型 2/13（拆了一层又一层／衣橱大换血）；人群情境型 2/13（青春期的"小山丘"／快节奏生活下的眼周问题） |
| 适用 | STD / HEALTH 通用 |
| 不可照搬 | 「二月春风似剪刀」「每款韭菜美食都很能打」等独特措辞 |

### R-02 引用标准必用「《标准全称》（编号）」格式
| 项 | 内容 |
|---|---|
| 维度 | 术语与标准处理 |
| 可执行 | 首次提到某标准，必须写书名号全称 + 括号内标准号，如《密胺塑料餐饮具》（GB/T 41001-2021）；不写简称、不省编号 |
| 证据 | **12/13（92%）**，代表：02 卸妆、03 餐具、04 防晒、07 快递包装、11 车内空气 |
| 例外 | #09 眼霜篇未出现该格式 |
| 适用 | STD |
| 不可照搬 | 各篇的完整标准号清单（属本次事实，需重新核验） |

### R-03 正文必含带编号的标准，中位数 2 个
| 项 | 内容 |
|---|---|
| 维度 | 资料密度 |
| 可执行 | 每篇正文至少引 1 个带编号标准；常见 2 个；最多 6 个（#09）。不堆砌标准号，每个都要在正文里被解释 |
| 证据 | 12/13（92%）；每篇标准数中位数 2、区间 1–6 |
| 适用 | STD |

### R-04 结尾必有「来源清单」模块
| 项 | 内容 |
|---|---|
| 维度 | 结尾 |
| 可执行 | 正文结束后空一行，加模块名，逐条列出标准全称或文献；条目数中位数 4 |
| 证据 | **12/13（92%）** |
| **关键例外** | **模块名不固定**：「内容参考」6 篇 /「内容来源」6 篇，五五开 → 规则写成"必有来源模块"，**不要写死模块名** |
| 例外 | #10 春日韭菜篇无来源模块 |
| 适用 | 全部 |

### R-05 篇幅：正文 1000–1900 字，典型 1400
| 项 | 内容 |
|---|---|
| 维度 | 篇幅 |
| 可执行 | 目标 **1300–1500 字**；下限不低于 1000，上限不超过 1900 |
| 证据 | 实测分布（13 篇）：1042 / 1074 / 1094 / 1096 / 1274 / 1388 / **1401** / 1412 / 1432 / 1489 / 1615 / 1831 / 1915；P25=1096、P50=**1401**、P75=1489 |

| 适用 | 全部 |

### R-06 段落节奏：段数中位 24，平均段长中位约 58 字

|---|---|
| 维度 | 段落节奏 |

### R-07 几乎不用感叹号

|---|---|

### R-08 用 emoji 作要点/小标题标记

## 二、T 级规则（可注入，但须标注"倾向，允许偏离"）

### T-01 系列/栏目稿用「系列名 ｜ 副标题」
- **可执行**：属固定系列的稿件，标题写成 `系列名` + 竖线 + `副标题`，仅此一处用竖线
- **证据 7/13（54%）**，但**系列内命中率 100%**：「那点事」系列 6/6（卸妆／防晒／祛痘／眼霜／春季护肤／唇膏）＋「热点追踪」栏目 1/1
- **例外**：非系列稿不带竖线（6/13）
- **注意**：竖线有全角 `｜`、半角 `|`、误写 `l` 三种形态，规范写作时统一用 `｜`

### T-02 引标准前用引导词
- 可执行：用「依据／根据／按照」引标准，不用"有研究表明""据悉"这类无源表述
- 证据 8/13（62%）｜例外 5 篇直接以书名号起句

### T-03 用「标准规定／明确」转述条款
- 可执行：转述条款时用"标准明确，……""标准规定，……"，把条款变成可读句子而非原文照录
- 证据 8/13（62%）｜代表：03 餐具、06 祛痘、07 快递

### T-04 小标题问句化
- 可执行：全篇至少一个小标题用问句（正文问号合计 22 处）
- 证据 9/13（69%）

### T-05 给术语下定义
- 可执行：出现专业名词时用"×× 是指……"给出定义，随后接通俗解释
- 证据 6/13（46%）

### T-06 交代标准的强制/推荐属性
- 可执行：引标准时说明是推荐性还是强制性（"必须符合"用于强制性）
- 证据 5/13（38%）→ **低于我此前的判断**，此前基于 docx 4 篇得 3/4

## 四、本次统计中我自己纠正的三处错误（留档）

| # | 错误 | 后果 | 处置 |
|---|---|---|---|
| 1 | `unicodedata.normalize("NFKC")` 把全角标点压成半角 | "感叹号 0 处"是假数据（实为 2 处）；标点风格判断失真 | 移除 NFKC，全库重抓 |
| 2 | docx→md 的 `![](data:image...)` 未清理 | 图片语法混入正文，篇幅统计虚高约 200–500 字 | 增加 Markdown 图片语法清理，全库重抓 |
| 3 | 仅凭 4 篇 docx 稿就断言"标准引用三段式 4/4" | 该 4 篇恰是标准密度最高的，属样本偏差；全量实测仅 6/13 | 规则降级为 T 级，并在证据表注明 |

> 这三处正是"每条规则必须带真实频率"的价值所在：**只读少量样本会得出看似整齐、实则错误的规则。**

## 五、不可照搬项白名单（防洗稿硬约束）

以下属原文独有表达，**写作时禁止复用**：
- 独特比喻与自创说法：「剥洋葱」快递、「衣橱大换血」、「小山丘」、「涂了个寂寞」、食品界的"变形金刚"
- 标志性句式：系列稿的固定副标题（「白雪凝琼貌，明珠点绛唇」等诗句）
- 具体案例与品牌：olive young、GAMA、具体抽检批次与批次号
- 具体数值与条款：全部标准号、限值、日期 → 每次写作必须重新核验

**允许沿用**：段落长度区间、开篇锚点的类型、小标题的型态、来源模块的位置与结构、行文节奏。
