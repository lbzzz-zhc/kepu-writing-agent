# 风格证据表 v1.0

> **用途**：给《个人风格手册 v1.0》与《风格规则表 v0.3》的**每一条说法配一份可核对的依据**。
> 每条含：依据篇数、频率、等级、例外、数据出处。**没有依据的条目不得进入本表**（防"伪规则"）。
> **基准**：79 篇计入（2020-08-14 → 2026-09-09）
> **复算方式**：`python tools/style_report.py 10_知识库/01_历史语料库 --md 10_知识库/02_风格规则库/风格体检报告.md`
> 下表所有数字均可在重跑后的报告对应章节中逐条核对。

## 六、复算与升版纪律

```bash
# ① 重跑体检（所有数字的唯一来源）
python tools/style_report.py 10_知识库/01_历史语料库 \
       --md 10_知识库/02_风格规则库/风格体检报告.md

# ② 规则表按新数据修订后，重建页面并同步提示词注入区
python tools/build_site.py --project . --out docs --sync-prompt
python tools/build_writer.py --project . --out docs
```

- **只加样本**：出现新案例、新口语习惯 → 只进 KB1，不动规则。
- **升级规则**：同一新特征在 **≥3 篇**出现且与现规则冲突 → 才修订规则表，并记版本号。
- **降级规则**：近 6 个月 0 命中 → 降为 T 级或移入观察区。
- **本表与规则表数字必须一致**；不一致时以**重跑后的报告**为准，两份文件同时改。
