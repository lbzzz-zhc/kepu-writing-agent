# 文体变体手册 v0.1

> 更新：2026-09-14　依据：79 篇实测（`风格体检报告.md`）
> 用途：写作前**先判文体**，再按对应变体调整标题、结构、语气、资料要求与结尾。
> 与《栏目与系列变体手册》的关系：**本手册按文体（内容性质）切**，那份按栏目/系列切，两者互补。

---

## 判定顺序（先判文体，再判栏目）

```
① 有没有标准号／限值／条款要交代？ ── 有 → STD（标准与热点解读）
② 主题是"怎么选、别买错"？      ── → AVOID（消费避坑）
③ 主题是"怎么吃、有没有营养"？    ── → HEALTH（健康与营养）
④ 主题是"怎么用、别出事"？       ── → SAFETY（产品安全与使用提醒）
⑤ 都不像                          ── → MISC（按 STD 的骨架走，去掉标准段）
```

判定有歧义时**取更靠前的**（STD > AVOID > HEALTH > SAFETY），因为靠前的文体约束更强。

---

## 一、STD　标准与热点解读（41 篇 · 最大类）

| 维度 | 写法 |
|---|---|
| **触发** | 新国标发布/实施、监督抽查、行业乱象、某类产品的标准要求 |
| **标题** | 中位 16 字；**带问号 59%**；常用"口语悬念"（`A级鲜鸡蛋，究竟有多鲜？`）或"反差/纠偏"（`都是淀粉、没营养？午餐肉表示很委屈`） |
| **开篇** | 时令或新闻由头起，首段**不提标准**（100%）；主题压到第 2–3 句 |
| **结构** | 由头 → 概念澄清 → **标准怎么说**（2–4 个标准）→ 关键指标解读 → 消费者怎么办 → 来源标注 |
| **小标题** | 中位 6 个；**问句式小标题 85%**（该类特征最突出） |
| **标准密度** | 中位 **2 个**（最高之一）；必用「属性 +《全称》（编号）+ 原文 + 白话」四段式 |
| **篇幅** | 中位 **1245 字**；段数中位 21／段长中位 56 字 |
| **来源模块** | **87% 有标注**，其中 68% 是独立模块；模块名以 `内容参考` 为主 |
| **语气** | 解释者口吻，克制；零感叹号 98% |
| **资料要求** | **必须有标准原文或官方发布**；限值、条款号缺一不可核 |
| **易错** | 把标准号写错；混淆推荐性（GB/T）与强制性（GB）；把旧版限值当新版用 |

## 二、HEALTH　健康与营养科普（29 篇 · 第二大类）

| 维度 | 写法 |
|---|---|
| **触发** | 某类食物的营养成分、饮食误区、时令食材 |
| **标题** | 中位 16 字；带问号 55%；常用"身份代入"（`我被"儿童食品"套路了吗？`）或拟人（`常温奶、冰鲜奶，你更钟情谁？`） |
| **开篇** | 生活场景或身体感受起（`总有一些人，一喝牛奶肚子就会咕噜咕噜不舒服`） |
| **结构** | 场景/困惑 → 成分或原理 → 与相近品类**辨析**（A vs B）→ 怎么吃/怎么选 → 来源标注 |
| **小标题** | 问句式 59%；常用辨析型小标题（`固体饮料 VS 保健食品`） |
| **标准密度** | 中位 **1 个**（最低类）—— 只在涉及限量/定义时引 |
| **篇幅** | 中位 **1061 字（最短类）**；段数中位 19／段长中位 54 字 |
| **来源模块** | **72% 有标注，但仅 17% 用独立模块** —— 该类**主要用行内标注**（`内容来源：媒体综合整理`） |
| **语气** | 最生活化；零感叹号 86%（该类是唯一会用感叹号的，但仍 ≤1 处/篇） |
| **emoji** | **59% 使用**（全库最高）—— 可用作信息锚点（🌰 冷知识、🥚 挑选要点） |
| **资料要求** | 营养成分表、膳食指南、行业标准；**涉及健康声称必须可溯源** |
| **易错** | 越界做医疗建议（"能治/能防"）；不写适用人群与禁忌；用绝对化表述 |

## 三、SAFETY　产品安全与使用提醒（6 篇）

| 维度 | 写法 |
|---|---|
| **触发** | 某类产品误用风险、季节性安全隐患、新规实施 |
| **标题** | 中位 **18 字（最长类）**；带问号 67% |
| **开篇** | **风险场景**起（`寒冬腊月，洗澡水忽冷忽热，不仅洗得不舒服，还可能刺激血管收缩`） |
| **结构** | 风险场景 → 为什么会出事 → 标准/规定怎么说 → **正确用法若干条** → 来源标注 |
| **小标题** | 问句式仅 33%（最低类）—— **多用名词短语式**（`选购与使用注意事项`、`使用时确保水质达标`） |
| **标准密度** | 中位 **2 个**（与 STD 并列最高）—— 安全要求必须落到条款 |
| **篇幅** | 中位 **1348 字（最长类）**；段长中位 **71 字（最长）** —— 该留白少、信息密度高 |
| **来源模块** | 83% 有标注，其中 66% 独立模块 |
| **语气** | **严肃但不吓人**：风险必须带条件与边界（`若冷水/热水突然中断……`）；不写"千万别""必死" |
| **资料要求** | 标准条款 + 事故/抽查通报；**风险描述必须有依据** |
| **易错** | 制造恐慌；把个别案例写成普遍风险；不给正确做法就结束 |

## 四、AVOID　消费避坑指南（3 篇 · 样本最少）

| 维度 | 写法 |
|---|---|
| **触发** | 某类商品"怎么选、怎么辨别、别花冤枉钱" |
| **标题** | 中位 **12 字（最短）**；**带问号 100%** |
| **开篇** | 疑问或"算账"起（`便宜的几块钱一斤到贵的几十块一斤，这些肉丸都有什么区别呢？`） |
| **结构** | 价格/选择困惑 → 差别在哪 → 标准怎么定 → **避坑要点（数字清单）**→ 来源标注 |
| **标志性手法** | **数字口诀清单**（`三不原则`、`两要两不要`）——该类最鲜明的特征 |
| **篇幅** | 中位 1155 字；段数 22／段长中位 **50 字（最短）** |
| **来源模块** | 66% 有标注 |
| **资料要求** | 执行标准、抽检数据、价格区间 |
| **⚠ 样本不足** | **仅 3 篇，规则均为 O 级**。写作时若判为该类，**必须先提示"该变体样本不足"**，不得声称已严格遵循 |

## 五、跨文体对照表（一眼看差异）

| 维度 | STD | HEALTH | SAFETY | AVOID |
|---|---|---|---|---|
| 篇数 | 41 | 29 | 6 | 3 |
| 篇幅（中位） | 1245 | **1061** | **1348** | 1155 |
| 段长（中位） | 56 | 54 | **71** | **50** |
| 标准数（中位） | 2 | 1 | 2 | 1 |
| 标题长度 | 16 | 16 | **18** | **12** |
| 带问号标题 | 59% | 55% | 67% | 100% |
| 有来源标注 | **87%** | 72% | 83% | 66% |
| 独立来源模块 | **68%** | **17%** | 66% | 33% |
| 问句式小标题 | **85%** | 59% | **33%** | 67% |
| emoji | 27% | **59%** | 17% | 67% |
| 零感叹号 | 98% | 86% | 83% | 100% |

**三条最实用的跨文体差异**：
1. **健康类把来源写在行内**（独立模块仅 17%），标准类相反（68%）—— 按文体决定来源形态，别一刀切。
2. **安全类段落最长、篇幅最长**（段长 71 字、1348 字），因为它要把"为什么危险 + 怎么才对"都写清。
3. **问句式小标题是标准类的招牌**（85%），安全类几乎不用（33%）—— 安全类用小标题更像"条目式提醒"。

## 六、写作前的变体自检（4 问）

1. 选题里有没有**必须交代的标准/限值**？→ 有则按 STD 处理，标准段不可省。
2. 读者最想解决的是**"买哪个"**（AVOID）、**"能不能吃/有没有营养"**（HEALTH）、还是**"会不会出事"**（SAFETY）？
3. 判出的文体**样本是否 ≥5 篇**？不足（AVOID 3 篇）→ 必须提示"样本不足"。
4. 该文体的**来源形态**是哪一种（独立模块 / 行内）？按表选，别套错。
