## 二、变体 A：「那点事」护肤美妆系列（7 篇）

### 标题
- **固定格式**：`X那点事` + 竖线 + 副标题，**系列内 7/7，无一例外**
- 副标题两种写法，大致各半：
  - **诗句/文言型**（3 篇）：白雪凝琼貌，明珠点绛唇｜肌肤炯凝脂，容色眩春雪｜"肤若凝脂"如我所愿
  - **白话型**（4 篇）：皮肤状态越来越差，会不会是妆没卸干净？｜全年无休的"光损伤"，比你想象的更可怕｜谁说青春一定要留下痘印？｜美目清兮，如何养护你的双眸？
- 竖线写法不统一（`｜`／`|`／误作 `l`）→ 规范写作统一用全角 `｜`

### 结构（7 篇一致）
成分/质地分类 → 标准定义（含标准号） → **常见质量问题**（监督抽检、限量指标） → 使用与选购建议
- 「常见质量问题」是这一变体的**标志性小节**（卸妆、餐具式抽检、春季护肤的"菌落总数超标"等）

### 语气
偏"养护关怀"，比其他变体更多体验化表达：容貌焦虑、如天鹅绒般柔嫩细腻、温润玉肌
> ⚠️ 这一变体是唯一出现**情绪化形容词**的地方，但不越界到恐慌式

### 资料要求（最高）
- 每篇引 2–6 个标准（全库最高）
- 会引用《化妆品安全技术规范》《质量与标准化》杂志，甚至学术论文（卸妆篇引《日用化学品科学》2023 年刊文）
- 会引用监管部门抽检通报（上海市药监局 2025 年抽检）

### 结尾
来源模块 + **安全提示**：「使用前务必皮肤测试」「敏感人群怎么办？」→ 把风险提醒放在结尾

## 三、变体 B：「热点追踪」栏目（1 篇，样本不足）

- 标题：`热点追踪｜` + 新闻式标题
- 开篇：**公众争议现象**切入（"拆了一层又一层，还是没有看到自己的心头好"），不是时令
- 结构：现象/吐槽 → 往年监督抽查情况 → 新规要点（层数 ≤2 / ≤3）→ 对消费者的影响
- 语气：**比其他变体更直接**，允许轻微吐槽（"不由令人泄气"）
- 资料：新旧规对比 + 监督抽查历史数据
- **⚠️ 仅 1 篇，本手册仅记录栏目定位，不产出规则**。补到 ≥3 篇再写差异。

## 四、变体 C：生活消费品标准解读（6 篇）

### 标题
无固定格式，三种型态混用：
- 反差设问型：密胺怕热、不锈钢怕咸？这份餐具"避坑"指南请查收
- 疑问句尾型：换季洗衣，你选干洗还是水洗？｜春暖花开踏青去，你的车内空气达标了吗？
- 定位陈述型：马海毛：冬季衣橱里的颜值担当｜冬季的电磁炉，不只是涮火锅

### 结构
品类定义 → 标准与性能指标（**图注常带标准号**，如 `GB/T 23128-2008：效率等级指标`） → 选购要点 → **洗护/使用注意**
- 标志性小节：**"三不原则""两要两不要"式的数字口诀清单**（餐具篇最典型）

### 语气
**实用导向，动作动词最多**：试水温／看洗标／配锅／摸内外两侧
第二人称最多（"你选干洗还是水洗？""你得知道大米怎么选"）

### 资料要求
1–4 个标准，偏"产品性能指标"（效率等级、物理力学性能、耐热耐低温）

### 结尾
**最容易缺来源模块的变体**（6 篇中 1 篇无）→ 常以"洗护清单"或"注意事项"收尾，而非总结句

## 五、变体 D：食材与饮食科普（7 篇）

### 标题
题材化、口语化最明显：
- 拟人/比喻：这份"水+粉"的快乐，一定要喝得明明白白｜在火锅的世界里，一定少不了牛肉丸
- 攻略式：想吃一碗好饭？你得知道大米怎么选→｜吃啥米｜胚芽米、GABA米是什么→
- 时令式：别错过这一茬！春日韭菜正当食｜节后"甩肉"，不妨尝试低嘌呤饮食

### 结构
是什么 → 分类 → **营养/成分怎么看** → **与相似品区分** → 怎么选
- 标志性小节：**辨析类小标题**（"固体饮料 VS 保健食品""肉丸与肉丸大不同""不是所有的牛肉丸都叫潮汕牛肉丸""全麦vs非全麦"）

### 语气
**生活化程度最高**：快乐、暖心大法、基因里的温暖仪式、一束金
但**健康结论必写适用边界**（低嘌呤篇写"适用于…"、韭菜篇给"选购建议"）

### 资料要求
食品标准 + 行业标准（GB/T 29602、GB 28050、DBS 44/005）＋ 机构数据（中国疾控中心营养与健康所）
- 会出现**方言/地方标准**（DBS 44/005 潮汕牛肉丸）

### 结尾
来源模块 4/7；常用"怎么选"行动清单

- 银杏《风起金浪，又到银杏醉美时》、草坪《公园的草坪，有的发黄、有的常绿…》

## 八、变体判定规则（写作时先定变体，再定写法）

1. 主题属护肤美妆个护 → **变体 A**，标题必须用系列格式
2. 主题由**新闻/新规/公众争议**触发 → **变体 B**
3. 主题是**家居/衣物/电器等耐用品**怎么用、怎么挑 → **变体 C**，结尾给清单
4. 主题是**能吃能喝的东西** → **变体 D**，必须写辨析段 + 适用边界
5. 主题是**自然现象、季节物候** → **变体 E**（当前样本不足，慎用，须人工确认）
6. 判定不唯一 → 停下来问作者

## 九、跨变体不变的底层（任何变体都得守）

以下取自《风格规则表 v0.2》，在全部变体中一致（23/23）：
- 首段 30–110 字，**不出现标准号、"标准""规定"字样**
- 全文几乎不用感叹号（23 篇中 21 篇零使用）
- 标点全角统一、段落中位 24 段、平均段长中位 57 字
- 引用标准用《全称》（编号）格式，每篇至少 1 个
- 数字与结论必须可溯源，不写无源"专家表示"
