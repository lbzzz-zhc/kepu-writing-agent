# KB3 · 本次事实资料库

## 一句话定位
**"这一篇的事实从哪来"——只认这一层，不认历史文章。**

## 目录结构
```
KB3-20260912_安全帽热点/
├─ sources/                     # 原始资料（标准文本、官方通告、权威报道）
│   ├─ GB-30041-2025.pdf
│   └─ 市场监管总局通告_20260810.md
├─ 事实底稿.md                   # 唯一事实入口，写作只能引用这里
└─ 待核验清单.md                 # 缺来源/待确认项，需你补料
```

## 事实底稿的每条记录格式
| 字段 | 说明 |
|---|---|
| 编号 | F01、F02… |
| 事实点 | 一句可直接进正文的陈述 |
| 类型 | 标准号 / 条款 / 限值 / 日期 / 机构 / 研究结论 / 行业数据 |
| 数值与原表述 | 原文照录，不得改写数字 |
| 来源 | 标准号+条款号 / 机构+文件名 / 链接 |
| 核验状态 | 🟩 已核验 · 🟨 待核验 |
| 核验日期 | YYYY-MM-DD |
| 可用于哪一段 | 对应结构骨架的哪一节 |

## 三条铁律
1. **🟨 待核验**的内容**不得写入成稿**；
2. 成稿中的每个数字、标准号、日期，都必须能在此表找到 🟩 记录；
3. **历史语料库（KB1）永不出现在此目录的来源列中**——旧文章不是事实来源。

## 缺料时的固定话术
> ⏸ 已暂停：事实底稿中 F__、F__ 缺来源。请补充【具体文件/官方链接】。
> 我不在资料不足时先写占位稿。
