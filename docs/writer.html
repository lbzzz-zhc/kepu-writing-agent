最终成稿

语料入库 · 让智能体学习新文章

把新的公众号文章链接粘进来，一键抓取并存入历史语料库，然后自动重算风格特征。 此功能需要本地服务在运行：python tools/writer_server.py。 浏览器不能写磁盘、也不能跨域抓微信链接，所以必须由本机服务代劳。

入库只进 KB1（仅用于风格）；新文章里的标准与数据永远不作为写作事实来源。

为什么需要你自己的 API

静态网页本身不能生成文字，必须调用一个模型接口。为了不把你的 Key 放在任何服务器上， 本页直接把请求发给你填的接口地址；如果你的接口没开跨域，就跑一下本地小服务 python tools/writer_server.py（在本机 8787 端口起一个转接）， 然后在上面勾选「走本地代理端口」。
